# 云端 Agent：代码与架构审查

日期：2026-11-15。范围：本轮新增/修改的服务端、运行包、契约、迁移、测试和部署文档；并检查现有第一方 TS/TSX 的公共入口与依赖关系。不是对 LobeHub、Pi 或 E2B 全仓库的安全审计。完整 TypeScript 代码规范原文未修改。

## 职责与接口

- agents 管定义、可见性和授权读取；sessions 管会话输入、取消、展示快照与订阅；tasks 管 Run 所有权、派发、工具回执和最终提交。
- bootstrap 绑定 SDK、E2B 与业务工具。Pi 适配器解释 SDK 事件和原生检查点；E2B 适配器拥有远端命令、取消与暂停。平台不通过多层转发才能找到执行主线。
- 共享执行接口只包含本轮需要的观测、JSON 检查点和工作环境能力。没有全量 SDK 镜像、唯一实现对应的策略类、空注册表、通用工作流引擎或并行会话格式。
- 数据库模块提供连接、事务类型、schema；业务事务仍归所属功能。SDK 工具清单不塞进通用运行包。跨功能使用公开入口，基础设施不导入业务入口。

## 本轮发现并修复

| 问题 | 修正与验证 |
| --- | --- |
| Pi 把 Runner 的 cwd 传给远端工具 | Session 显式使用沙箱目录；受控 SDK 和真实沙箱调用验证相对路径 |
| Bash 大输出文件留在 Runner，模型拿到不可用路径 | 复用 SDK 截断，通过文件 Blob 转到沙箱，修正结果路径并释放临时文件；SDK 测试验证完整内容 |
| 平台 Session 直接理解 Pi 文件引用 | 改为执行器检查点 JSON，Pi 单独解析 kind/version/路径；迁移保留已有引用 |
| 旧 owner 可能改写已提交会话文件 | 每次 attempt 复制 SDK 原始字节，在独立目录继续；文件缺失或格式不兼容明确失败 |
| SDK 订阅不等待异步持久化 | 执行资源按序等待接收确认，保留投递失败并停止 SDK；终态等待消息和资源收尾 |
| SDK 普通 PID kill 留下命令子进程 | 远端独立进程组取消，并等待确认；真实测试验证普通子进程停止 |
| 取消与模型成功提交竞态 | 最终事务检查当前取消和授权，已提交取消优先；独立故障和未知效果不被取消掩盖 |
| 工具执行成功但确认丢失可能重复副作用 | 执行前写意图，确认后写回执；pending 和过期 owner 隔离为 recovery_required |
| 有资源的 Workspace 级联删除使沙箱失去归属 | 官方组织删除 hook 返回 409，外键 restrict 兜住并发创建；沙箱带最小归属元数据 |
| Worker 清理失败时可能跳过等待消费循环 | 收尾等待资源释放和消费循环，保留独立清理失败 |
| 邀请测试精确比较 SDK 两次取时，偶发相差 1 毫秒 | 改为在请求前后时间范围内验证七天有效期，不改业务有效期 |
| BullMQ 保留领取前失败的任务 ID，挡住 PG 待执行记录再次唤醒 | 失败唤醒不留队列身份；PG queued 才能重投，已领取/不确定 Run 不重跑；真实回归验证 |
| 共用 PG 的集成测试并行启动 Worker 相互领取输入 | 测试文件串行运行；不在生产查询加入测试过滤条件 |

## 代码形状

逐模块检查输入边界、状态所有者、失败方式、异步任务与资源顺序。辅助 AST 扫描读取了 apps/packages/tests 下 110 个 TS/TSX 文件，检查生产代码嵌套、断言、导出返回类型及相对导入环。未发现生产代码超过约定块嵌套、非空断言、any、强制类型断言或相对导入循环；JSX 组件按规范保留返回类型推断。此扫描不是类型感知 lint，也不能替代人工职责审查。

sessions/store.ts 包含同一 Session 的访问、输入、配置、取消和快照规则；保留集中实现，以免按执行阶段拆分后把锁、幂等和覆盖顺序交还调用者。公开导出具名，跨包使用 exports，SDK 的类型和协议留在对应适配器/组合根。英文注释重点解释确认边界、凭据隔离、取消和释放顺序。

未增加吞错兜底、旧实现并存或本机执行回退。未启用的工具不暴露；无模型连接时关闭执行能力，不伪造可用目录或成功响应。

## 第二轮完整复核

按 AGENTS.md 重读完整代码规范后，重新检查生产模块、关键测试、迁移与 CI；静态扫描范围仍为 110 个 TS/TSX 文件。未改变模块划分，也未修改规范原文。本轮确认并修复以下问题：

| 级别 | 已复现的问题 | 修复位置与证据 |
| --- | --- | --- |
| P1 | 已登出或已过期的登录仍能通过原有 SSE 连接接收新内容 | sessions/stream.ts 重新核对登录；真实认证连接测试覆盖 logout 与 expiration |
| P1 | 文件传输取消被当作远端效果已确认，pending 意图错误清除 | tasks/workspace.ts 仅认可命令适配器的终止确认；先复现 cancelled，再验证 recovery_required |
| P1 | SDK 并发创建不同邀请时，同一 Workspace/用户可产生两条成员记录 | workspace-schema.ts 新增唯一索引；延续现有精确版本 SDK 补丁，在原有成员事务中加组织锁与成员检查；真实 SDK 回归先复现双成功，修复后一次成功、一次明确的业务拒绝 |
| P2 | 不同用户并发接受邀请可突破 SDK 成员人数上限 | 将原有上限判断移至同一成员事务与组织锁内，真实 SDK 测试验证总成员数不会超过配置 |
| P2 | 排队取消、过期 owner 等 PG 状态缺少通知，已有订阅永久显示旧状态 | 空闲时按授权读取的 Session revision 同步持久快照；覆盖无 Worker 事件的取消与隔离 |
| P2 | 用户沙箱文件在 Pi 截断前被整份下载到可信 Runner | 直接消费官方流式读取，限制实际字节为 20 MiB；真实测试验证边界大小、超限拒绝和后续操作 |

成员唯一约束通过新增 0006 迁移建立，不改写已应用迁移，不自动合并或删除重复成员；若现存数据违反约束，迁移明确失败，需人工核对。新的复合唯一索引同时覆盖 Workspace 查询，移除重复的单列 Workspace 索引。SDK 补丁仅扩大现有组织事务锁的使用，保持原生邀请协议与错误处理，升级时由 SDK 测试验证。

文件读取使用 Node Web Stream 的 async iteration；提前结束会取消下载并释放连接，依据 [Node 官方文档](https://nodejs.org/api/webstreams.html#readablestreamvaluesoptions) 和已安装 E2B 2.64.0 的 FilesystemReadOpts/read 声明。本轮沙箱功能测试还确认了实际运行行为。

订阅修复只在原模块增加登录能力和 revision 对账，不增加另一套事件总线或永久流日志。PG 快照不包含未提交草稿，因此明确客户端合并规则：终态优先；pending 累计文本不向后缩短。相关协议已经同步到 [云端 Agent 后端](../cloud-agent.md)。

## Session 代码形状复核

路由入口集中展示方法、路径和校验器，随后直接注册具名处理函数；输入类型从实际 schema 推导。stream.ts 拥有 HTTP 流的启动、取消和失败报告，路由处理只负责请求校验及访问准入。后续全仓的结构调整和验证见 [全仓审查记录](codebase-style-2026-11-15.md)。

store.ts 的公共操作保留事务、授权、重复输入和恢复判断；recordSessionInput 集中 Inbox、Run、用户消息与 revision 必须共同提交的顺序，readSessionView 集中当前 Run 选择及展示映射。访问读取返回经过解析的 Session，存储引用留在内部；无效的持久配置在写入新输入前拒绝，已补真实 PG 回归。

本机 TypeScript 7.0.2 编译器及其语言服务均确认六个事务回调为具体 PgTransaction；未使用断言或 any。用户报告的编辑器 ts(7006) 暂未在当前工作区复现，需结合其编辑器项目配置继续核对。

## 保留的边界

当前不是生产高可用/容量验收：没有完整强杀故障矩阵、自动副作用对账、恢复操作 API、旧检查点/暂停沙箱回收、长历史分页、跨版本压缩上下文迁移或任意跨供应商长对话保证。正常原生会话接续与异常中途恢复分别处理，不能混为同一承诺。

运行依赖持久会话目录；多机器须明确共享该存储。流保存有期限，累计草稿增加长文本传输量，尚未压测。进程组取消不撤销已发生效果，也不承诺处理特意脱离会话的后台服务。删除/回收生命周期和未知效果核对仍需后续业务设计。

这些边界、配置和接口在 [云端 Agent 后端](../cloud-agent.md) 与 [E2B 本机部署](../../deploy/e2b/README.md) 中列出。Router、Timers、Memory 整理、审批、Outbox 和本地 Connector 不在本轮范围内。
