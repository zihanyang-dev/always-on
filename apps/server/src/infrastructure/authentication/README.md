# 登录认证

已接入 Better Auth：Google、GitHub、邮箱密码、验证邮箱、找回密码、登录会话和退出。SDK 路由挂载在 `/api/auth/*`；`getUser` 只提供经过白名单解析的用户资料。账号、会话和验证记录保存在 PostgreSQL；Redis 只负责原子限流。

用户、工作空间、成员角色与资源访问规则归对应业务功能，Agent 操作授权归 agents/tasks；不因认证接入放在 infrastructure，就把账号业务和权限判定全部放进这里。

邮箱密码登录要求先验证邮箱。密码重置会撤销已有会话；Cookie 缓存关闭，后续请求重新查询持久会话。启用 SDK 的 OAuth token 加密选项。同邮箱的不同登录方式需要在已登录状态下显式绑定，初次 OAuth 登录不自动合并账号。

SDK 延迟执行的邮件和会话更新由本模块跟踪，HTTP 停止接收请求后等待收尾。当前邮件直接交给 Resend，进程异常退出时需要用户重新请求邮件；尚未实现持久邮件投递队列。发送有五秒超时，错误不记录邮件正文或令牌链接。

客户端 IP 来自 HTTP 连接，覆盖客户端自行提交的内部 IP 头。代理部署当前按代理连接地址计数；需要识别最终用户 IP 时，再配置明确可信的代理规则。

当前用户入口为 `/api/me`，详见 [认证接入说明](../../../../../docs/authentication.md)。Workspace/RBAC 与云端 Agent 后端已经接入，业务资源授权归各自功能；现有 SSE 会持续复核登录与成员身份。设备注册和业务前端尚未实现。
